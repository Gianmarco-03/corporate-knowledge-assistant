- Fonti documentali della sintassi, consultate il 2026-10-21. Il riferimento del Compose file (https://docs.docker.com/reference/compose-file/services/) dice che l'attributo `tmpfs` accetta `<path>:<options>`, con le opzioni `mode`, `uid` e `gid`.
